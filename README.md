# 🌌 太阳系 3D 可视化

一个基于 Three.js 构建的交互式太阳系 3D 可视化应用，展示真实天文比例的行星系统。

## ✨ 功能特性

### 3D 场景
- **太阳**：位于画面中央的发光体，带光晕效果
- **8 大行星**：水星、金星、地球、火星、木星、土星（带光环）、天王星、海王星
- **行星自转**：各行星按真实比例自转
- **椭圆公转**：行星沿椭圆轨道绕太阳公转
- **轨道可视化**：半透明椭圆轨道线
- **星空背景**：10000 颗星星构成的银河背景

### 交互功能
- **视角控制**：鼠标拖动旋转视角，滚轮缩放
- **行星详情**：点击任意行星弹出信息面板
- **控制面板**：
  - 公转速度滑块（0.1x ~ 10x）
  - 行星大小比例滑块（0.5x ~ 5x）
  - 各行星显示/隐藏开关
  - 轨道线显示开关

### 视觉效果
- 太阳光晕着色器效果
- 行星使用不同颜色区分
- 点光源照亮场景
- 深色太空主题，沉浸式宇宙氛围

## 🚀 快速开始

### 方法一：直接运行

使用浏览器直接打开 `index.html` 文件即可。

### 方法二：使用 Node.js

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

然后在浏览器中访问 `http://localhost:3000`

### 方法三：使用 Docker

```bash
# 一键启动
docker-compose up -d
```

然后在浏览器中访问 `http://localhost:3000`

## 🎮 操作指南

| 操作 | 效果 |
|------|------|
| 鼠标左键拖拽 | 旋转 3D 视角 |
| 鼠标滚轮 | 放大/缩小视野 |
| 点击行星 | 查看行星详细信息 |
| ESC 键 | 关闭信息面板 |
| 点击遮罩 | 关闭信息面板 |

## 📊 天文数据来源

本应用行星数据基于 **NASA 行星概况**，所有行星的相对大小比例和公转周期比例都基于真实天文数据：

| 行星 | 直径 (km) | 与太阳距离 (百万 km) | 公转周期 (地球日) | 自转周期 (地球日) |
|------|-----------|---------------------|------------------|------------------|
| 水星 | 4,879 | 57.9 | 88 | 58.6 |
| 金星 | 12,104 | 108.2 | 225 | 243 |
| 地球 | 12,742 | 149.6 | 365 | 1 |
| 火星 | 6,779 | 227.9 | 687 | 1.03 |
| 木星 | 139,820 | 778.5 | 4,333 | 0.41 |
| 土星 | 116,460 | 1,433.5 | 10,759 | 0.45 |
| 天王星 | 50,724 | 2,872.5 | 30,687 | 0.72 |
| 海王星 | 49,244 | 4,495.1 | 60,190 | 0.67 |

> **注意**：为了视觉效果，行星之间的距离进行了整体缩放，但是行星之间的比例关系保持正确。

### 模块化设计

- **UI 与 3D 逻辑分离**：控制面板和信息面板完全独立于渲染逻辑
- **配置驱动**：所有行星数据集中管理，便于维护和扩展
- **事件驱动**：模块间通过事件回调通信，降低耦合

## 🛠️ 技术栈

- **渲染引擎**：[Three.js](https://threejs.org/) (WebGL)
- **着色器**：自定义 GLSL 太阳光晕效果
- **样式**：CSS3 + Backdrop Filter 毛玻璃效果
- **字体**：Google Fonts (Orbitron + Noto Sans SC)
