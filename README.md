# 🌌 太阳系 3D 可视化

从零构建的太阳系 3D 可视化交互应用，基于 Three.js

## ✨ 功能特性

### 3D 场景
- 🌞 太阳作为发光体位于画面中央
- 🪐 8 大行星沿各自轨道公转
- 🔄 行星自转动画
- 📍 半透明椭圆轨道线可视化
- ✨ 星空背景

### 交互功能
- 🖱️ 鼠标拖动旋转视角
- 🔍 滚轮缩放
- 👆 点击行星弹出信息面板，显示：
  - 行星名称（中英文）
  - 直径
  - 与太阳距离
  - 公转周期
  - 行星简介

### 控制面板（左侧）
- ⚡ 公转速度滑块（0.1x ~ 10x）
- 📏 行星大小比例滑块（0.5x ~ 3x）
- 👁️ 各行星显示/隐藏开关
- 🔄 轨道线显示开关

### 视觉效果
- 💡 太阳点光源照亮行星
- 🎨 行星使用不同颜色区分
- ✨ 太阳光晕效果
- 🌌 深色太空主题，沉浸式宇宙氛围

## 🛠️ 技术栈

- **Three.js** - 3D 渲染引擎
- **Vite** - 构建工具
- **HTML5 / CSS3 / JavaScript (ES6+)** - 前端基础技术

## 🚀 快速开始

### 方式一：使用 npm

1. 安装依赖
```bash
npm install
```

2. 启动开发服务器
```bash
npm run dev
```

3. 打开浏览器访问 `http://localhost:3000`

### 方式二：使用 Docker Compose（推荐）

1. 一键启动
```bash
docker-compose up
```

2. 打开浏览器访问 `http://localhost:3000`

### 数据来源
- 行星相对大小比例：基于真实天文数据（地球直径 = 1）
- 轨道距离比例：基于真实天文数据（地球到太阳距离 = 1 天文单位）
- 公转周期比例：基于真实天文数据（地球公转周期 = 1 地球年）

## 🎨 设计特点

- **深色太空主题**：深蓝/黑色渐变背景
- **毛玻璃效果**：控制面板使用 backdrop-filter: blur
- **自定义控件**：滑块和开关使用自定义样式，非原生控件
- **过渡动画**：信息面板有淡入滑出动画
- **响应式设计**：适配不同屏幕尺寸

## 🏗️ 架构设计

### 模块分离
- `data.js` - 数据层：存储天文数据
- `scene.js` - 3D 层：Three.js 场景管理
- `ui.js` - UI 层：控制面板和交互
- `main.js` - 整合层：连接各模块

### 代码规范
- 所有 JavaScript 函数包含 JSDoc 注释
- 模块化设计，职责分离
- 遵循 ES6+ 语法规范
