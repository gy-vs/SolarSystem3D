# 🌌 太阳系 3D 可视化

交互式 3D 太阳系可视化应用，基于 Three.js 构建，支持实时交互控制。

## ✨ 功能特性

### 🎨 3D 场景
- **太阳发光体**：中心点光源，带光晕效果
- **8 大行星**：水星、金星、地球、火星、木星、土星、天王星、海王星
- **行星自转**：每个行星按真实比例周期自转
- **公转动画**：行星沿椭圆轨道公转
- **轨道线可视化**：半透明椭圆轨道线
- **星空背景**：10000 颗星星营造沉浸式宇宙氛围

### 🎮 交互功能
- **视角控制**：鼠标拖拽旋转 3D 视角
- **缩放**：鼠标滚轮缩放场景
- **行星详情**：点击行星弹出信息面板
- **公转速度调节**：0.1x ~ 10x 速度滑块
- **行星大小调节**：0.5x ~ 5x 缩放比例
- **行星显隐**：每个行星独立显示/隐藏开关
- **轨道线开关**：一键显示/隐藏所有轨道线

### 🎯 视觉效果
- 深色太空主题，沉浸式宇宙氛围
- 左侧控制面板半透明毛玻璃效果
- 自定义滑块和开关样式，与太空主题协调
- 行星信息面板精致卡片式设计
- 平滑的进入/退出过渡动画
- 每个行星使用不同颜色区分

## 🚀 快速开始

### 方式一：使用 Docker（推荐）

```bash
docker-compose up -d
```

然后在浏览器中访问 `http://localhost:3000`

### 方式二：本地开发

#### 安装依赖
```bash
npm install
```

#### 启动开发服务器
```bash
npm run dev
```

#### 构建生产版本
```bash
npm run build
```

#### 预览构建结果
```bash
npm run preview
```

## 📖 操作指南

| 操作 | 说明 |
|------|------|
| 🖱️ 鼠标拖拽 | 旋转 3D 视角 |
| 🔄 鼠标滚轮 | 放大/缩小场景 |

## 🏗️ 项目架构

```
SolarSystem3D/
├── src/
│   ├── modules/
│   │   ├── SolarSystem.js    # 3D 渲染核心模块
│   │   ├── ControlPanel.js   # UI 控制面板模块
│   │   └── InfoPanel.js      # 行星信息面板模块
│   ├── data/
│   │   └── planets.js        # 行星天文数据
│   ├── styles/
│   │   └── main.css          # 全局样式
│   └── main.js               # 应用入口
├── index.html                # HTML 入口
├── vite.config.js            # Vite 配置
├── package.json
├── docker-compose.yml
└── README.md
```

### 架构特点

- **模块化设计**：UI 控制面板与 3D 渲染逻辑完全分离
- **关注点分离**：每个模块职责单一，易于维护和扩展
- **类型安全**：所有函数包含完整的 JSDoc 注释
- **性能优化**：使用 WebGL 渲染，支持硬件加速

## 🛠️ 技术栈

- **渲染引擎**：Three.js ^0.160.0
- **构建工具**：Vite ^5.0.0
- **样式**：原生 CSS，使用 CSS3 变量和动画
- **容器化**：Docker + Nginx

## 📝 开发说明

### 代码规范
- 所有 JavaScript 函数必须包含 JSDoc 注释
- 使用 ES6+ 模块化语法
- 遵循函数式编程原则，保持纯函数
- 模块之间通过回调函数通信，避免紧耦合
